SCREENSHOTS - HONEST STATUS AND CAPTURE INSTRUCTIONS
=====================================================

Status: No GUI screenshots were captured inside the build environment
(it is a headless Linux VM with no display). Nothing in this folder is
a fabricated screenshot. The genuine execution evidence for this
project is the set of text logs in results/ (build_log.txt,
test_results.txt, tokens.txt, tac_output.txt, backpatch_trace.txt),
which are real, unedited command outputs.

To capture the six presentation screenshots on YOUR computer
(Ubuntu, or Ubuntu under WSL on Windows), run the commands below and
take a screenshot of the terminal after each one.

1. Successful build
   $ cd ~/compiler_design_workspace/if_else_compiler
   $ make clean && make
   Screenshot: terminal showing bison/flex/gcc lines, no errors.

2. Example input and generated TAC
   $ cat examples/if_else.src
   $ ./compiler examples/if_else.src

3. Nested if-else output
   $ ./compiler examples/nested_if_else.src

4. Backpatching trace
   $ ./compiler --trace examples/if_else.src

5. Passing automated tests
   $ make test

6. Syntax error detection
   $ ./compiler examples/invalid_syntax.src ; echo "exit code: $?"

How to take the screenshot itself:
- Ubuntu (GNOME): press Shift+Print Screen and select the terminal
  area, or run:  gnome-screenshot -w -f shot.png   (window capture)
- Scripted terminal capture without a camera (genuine text evidence):
    script -c "make clean && make && make test" session.log
  The file session.log then contains the full terminal session.
- Windows (WSL): open the terminal in Windows Terminal, use
  Win+Shift+S (Snipping Tool) and drag over the terminal window.
